# AI Content Factory

## Overview

AI Content Factory is an automated AI-powered content marketing system.

It creates short-form videos, generates captions, adds branding, and publishes content automatically to help promote digital products and drive traffic to a website.

---

## Features

- Read website content
- Generate AI video ideas
- Write TikTok scripts
- Generate captions
- Generate hashtags
- Generate AI voice
- Create vertical videos
- Add subtitles
- Add logo and branding
- Add website watermark
- Schedule automatic posting
- Support TikTok
- Support Facebook
- Support Instagram Reels
- Support YouTube Shorts

## Workflow

1. Read website
2. Find content ideas
3. Generate script
4. Generate AI voice
5. Create video
6. Add subtitles
7. Add branding
8. Generate caption
9. Generate hashtags
10. Publish to social media
11. Repeat automatically
